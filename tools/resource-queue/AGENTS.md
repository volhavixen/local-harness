# Resource queue

Необязательный локальный CLI; Python 3.9+ в POSIX-окружении (macOS/Linux/WSL), только стандартная библиотека. Нативная Windows не поддерживается из-за fcntl.
`heavy_check.py` — очередь, `test*.py` — полный набор проверок,
`state/` — общее состояние этого компьютера. Не коммитить и не удалять активный lock.

Проверки изменений: синтаксис `heavy_check.py` и всех `test*.py`, затем
`python3 -m unittest discover -v -p 'test*.py'`. Полный набор самотестов — класс heavy;
не объявлять его light только из-за малых отдельных фикстур. В рабочем использовании запускать через общую очередь;
самотесты используют свои изолированные state-каталоги, чтобы проверять конкуренцию.
Никаких установок зависимостей, изменения CI или автоматического E2E.
Сохранять коды завершения и не посылать сигналы процессам вне собственной команды.
Это cooperative-механизм: нельзя обещать перехват команд, запущенных напрямую.

Для новых рабочих заявок передавать `--label` (краткое название проверки) и
`--owner` (идентификатор чата/задачи). Для просмотра: `--status --human`,
для истории: `--history --human --limit 10`. Старый JSON-статус сохраняется.

Классы: по умолчанию heavy; --class light/network только для фактически малых
или сетевых независимых операций. Для них общий предел 2 и worker1; screen/Playwright
остаются heavy. Полные проверки/сборки — heavy. Не менять класс текущих процессов.
